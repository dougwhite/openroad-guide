# Contributing

Keep IDs stable; add a concise core entry, detailed article, native probe and shared agent case with hidden rubric. Begin at candidate status. Record native evidence before verified status. Include release/platform limits and conflicting observations. Never promote on documentation alone or a skipped test.

Prioritise mistakes observed in real work. Agent baseline success may justify removing a rule from the compact core while retaining the tested reference article. Keep all benchmark results, including no change and regressions. Test several trials; a single answer is anecdotal.

The next milestone is compiling the native starter and replacing pending skips. Later add realistic coding fixtures, executable grading, and configurable agent adapters. Do not add automation or gorak integration as part of the initial scaffold.
